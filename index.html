Cara berbelanja

  1. Cari produk atau pilih kategori. Klik gambar untuk melihat detail contoh.
  2. Tekan tombol + untuk memasukkan produk ke tas belanja.
  3. Atur jumlah di tas belanja, lalu lanjutkan ke WhatsApp setelah nomor penjual dikonfigurasi.
  4. Konfirmasikan stok, alamat pengiriman, ongkir, serta metode pembayaran dengan penjual. Situs tidak memproses pembayaran.

Terbitkan Ruang Kita

File ini belum otomatis diunggah ke GitHub. Repositori tujuan: markiantosibuea/ruang-kita.

  1. Unduh file index.html ini.
  2. Buka repositori Anda. Unggah melalui Add file → Upload files di akar repositori. Jika index.html sudah ada, perbarui file tersebut. Simpan perubahan dengan Commit changes.
  3. Buka Settings → Pages. Pilih Deploy from a branch, cabang main (atau cabang tempat file tersimpan), folder / (root), lalu Save.
  4. Setelah penerbitan berhasil, buka markiantosibuea.github.io/ruang-kita/. Alamat ini adalah tujuan penerbitan, bukan bukti bahwa situs sudah aktif.

Atur pemesanan WhatsApp

Untuk pengaturan permanen, edit nilai SELLER_WHATSAPP di kode. Nomor harus memakai kode negara, tanpa + atau spasi. Contoh format: 6281234567890. Jangan masukkan kata sandi atau token GitHub.

Harga dan detail produk dapat diubah pada data GROUPS di kode. GitHub Pages menayangkan situs statis; akun pelanggan, stok langsung, dan pembayaran otomatis memerlukan layanan tambahan.
